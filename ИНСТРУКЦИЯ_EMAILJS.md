# Инструкция по настройке отправки email из формы

Форма контактов настроена на отправку писем через сервис EmailJS.

## Быстрая настройка

### 1. Создайте аккаунт на EmailJS

Перейдите на [https://www.emailjs.com/](https://www.emailjs.com/) и зарегистрируйтесь (бесплатно)

### 2. Добавьте email сервис

1. В панели EmailJS перейдите в **Email Services**
2. Нажмите **Add New Service**
3. Выберите ваш почтовый сервис (Gmail, Outlook и т.д.)
4. Следуйте инструкциям для подключения вашей почты
5. Скопируйте **Service ID** (например: `service_abc123`)

### 3. Создайте email шаблон

1. Перейдите в **Email Templates**
2. Нажмите **Create New Template**
3. Вставьте такой шаблон письма:

**Тема письма:**
```
Новая заявка с сайта от {{from_name}}
```

**Текст письма:**
```
Получена новая заявка с формы обратной связи:

Имя: {{from_name}}
Email: {{from_email}}
Компания: {{company}}
Телефон: {{phone}}

Сообщение:
{{message}}

---
Это письмо отправлено автоматически с сайта Common Laser Technologies
```

4. **ВАЖНО!** Используйте именно эти переменные: `{{from_name}}`, `{{from_email}}`, `{{company}}`, `{{phone}}`, `{{message}}`
5. Скопируйте **Template ID** (например: `template_xyz789`)

### 4. Получите Public Key

1. Перейдите в **Account** → **General**
2. Найдите **Public Key**
3. Скопируйте его (например: `aBcDeFgHiJkLmN`)

### 5. Настройте переменные окружения

1. В корне проекта создайте файл `.env`:
   ```bash
   cp .env.example .env
   ```

2. Откройте `.env` и вставьте ваши данные:
   ```
   VITE_EMAILJS_SERVICE_ID=service_abc123
   VITE_EMAILJS_TEMPLATE_ID=template_xyz789
   VITE_EMAILJS_PUBLIC_KEY=aBcDeFgHiJkLmN
   ```

3. Сохраните файл

### 6. Перезапустите сервер

```bash
npm run dev
```

## Проверка работы

1. Откройте сайт в браузере
2. Прокрутите до формы "Связаться с нами"
3. Заполните форму и отправьте
4. Проверьте вашу почту - должно прийти письмо с данными из формы

## Бесплатный тариф

EmailJS бесплатно предоставляет:
- ✅ 200 писем в месяц
- ✅ 1 email шаблон
- ✅ 1 email сервис

Для большего количества писем нужно будет перейти на платный тариф.

## Что делать если письма не приходят?

1. **Проверьте папку "Спам"** - первые письма могут попасть туда
2. **Проверьте EmailJS панель** - там отображаются все отправленные письма и ошибки
3. **Проверьте переменные в .env** - они должны точно совпадать с данными из EmailJS
4. **Проверьте шаблон** - переменные должны быть написаны точно: `{{from_name}}`, а не `{from_name}`
